# 박해 (Persecuzione) — 체사레 리파의 의인화

> **Q.** 리파는 '박해(Persecuzione)'를 어떻게 의인화했는가?
>
> **A.** 녹청색과 녹 색깔이 섞인 옷을 입은 날개 달린 여인이 활을 당겨 쏘려는 자세이며 발치에 악어가 있다. 두 색은 남의 명예나 재산을 삭혀 없애려는 박해의 목적을, 날개는 남의 해악에 늘 재빠름을, 활은 멀리서도 악담으로 쏘아 해침을 뜻한다.

## 원문의 도상 묘사

리파의 원문(『Iconologia』, "PERSECUZIONE — Di Cesare Ripa")은 이렇게 규정한다.

> *"Donna vestita del color del verderame, accompagnato col color della ruggine. Alle spalle porta le ali, e nella sinistra tenga un arco, stando in atto di voler colpire; ed avrà a' piedi un Cocodrillo."*

즉 **① 녹청색(verderame)과 녹(ruggine) 색이 섞인 옷을 입은 여인**이 **② 어깨에 날개**를 달고, **③ 왼손에 활을 들어 막 쏘려는 자세(in atto di voler colpire)**를 취하며, **④ 발치에 악어(Cocodrillo)**가 있다.

- 참고: 이 판본의 스캔에는 '박해' 항목에 딸린 판화가 없다. 인접 항목인 '위험(Pericolo)'과 '완고(Pertinacia)'에만 삽화가 실려 있어, 이 카드는 텍스트 묘사만으로 학습한다.

## 상징 하나하나의 의미

### 1. 녹청색 + 녹 색깔의 옷 — 박해의 '목적'
- **verderame(녹청)**는 구리에 스는 푸른 녹, **ruggine**는 쇠에 스는 붉은 녹이다. 둘 다 금속을 **서서히 부식시켜 삭혀 없애는** 물질이다.
- 리파의 설명: 이 두 색은 "박해의 목적, 곧 **남을 소모시키는 것(consumar altrui)** — 명예(onore)에서든 재산(roba)에서든 — 을 뜻한다."
- 녹이 금속을 갉아먹듯, 박해는 사람의 명예와 재산을 조금씩 갉아 없앤다는 시각적 은유다.

### 2. 날개 — 해악에의 '재빠름'
- "날개는 박해가 **남의 해악을 향해 언제나 준비되어 있고 빠르다**(sempre presta, e veloce al male altrui)는 것을 뜻한다."
- 좋은 일에는 굼뜨지만 남을 해치는 일에는 즉각 날아드는 박해의 기민함.

### 3. 쏘려는 자세의 활 — '멀리서' 해치는 악담
- "활을 드는 것은 **멀리서도(di lontano) 악담하는 말(parole malediche)로 상처를 입히기 위함**이다."
- 박해는 직접 손대지 않아도 된다. 화살이 원거리 무기이듯, 중상과 비방은 멀리 떨어진 사람의 명예도 꿰뚫는다.

### 4. 발치의 악어 — 도망치는 자만 쫓는 비겁함
- 리파는 악어가 "**도망치는 자만을 뒤쫓아 싸움을 걸고, 맞서는 자에게는 그러지 않는다**"는 고대의 통념(악어는 쫓으면 달아나고, 달아나면 쫓는다)을 근거로 든다.
- 그래서 '박해'라 부를 수 있는 것은 **저항하지 않거나 저항할 뜻이 없는 사람에게 가해지는 힘**뿐이다.
- 리파의 예시: 남을 해칠 생각 없이 순순히 죽음을 받아들인 **성인(순교자)들이 당한 것**이 참된 의미의 박해이며, 명예로운 사람의 명성을 깎아내리는 데만 골몰하는 **시기하는 자·중상하는 자(invidiosi, detrattori)**의 행위도 박해다.

## 암기 포인트

| 요소 | 상징 |
|---|---|
| 녹청색·녹 색 옷 | 명예·재산을 녹슬 듯 삭혀 없애는 박해의 목적 |
| 날개 | 남의 해악에 늘 준비되고 빠름 |
| 당겨진 활 | 멀리서도 악담으로 쏘아 해침 |
| 발치의 악어 | 도망치는(저항 않는) 자만 뒤쫓음 |

기억법: **"녹슨 옷 입고, 날개 달고, 활 쏘고, 악어 데리고"** — 부식(목적) → 속도(성향) → 원거리 공격(수단) → 약자 사냥(대상) 순으로 박해의 본성을 4단계로 그린 그림이다.

## 곁들이는 이야기 (원문의 예화)

- **주석의 변주**: 각주에서 P. Ricci는 반대편, 곧 '의로운 자가 겪는 박해'를 그린다 — 초록(희망) 옷을 입고 발삼 가지를 든 여인이 별이 빛나는 하늘(의로운 피박해자가 받을 보상) 아래에서, 돌을 던지고 발을 묶으려는 자에게도 **웃는 얼굴로 말을 건네는** 모습. 묶는 밧줄 사이에 꽃이 피는 것은 박해가 선한 이에게는 명예와 영광의 꽃으로 바뀜을 뜻한다.
- **성사(聖史) 예화**: 예언자 **예레미야**는 유다 백성에게 담대히 설교하다 미움을 사 진흙 구덩이(마른 저수조)에 던져졌으나, 왕의 신하가 부당함을 아뢰어 구출되었다 (예레미야 38장).
- **속사(俗史) 예화**: 아테네인 **디오시포스**는 무공으로 시기를 사 집요한 박해를 받았고, 황금 잔을 훔쳤다는 모함까지 당하자 명예를 지키려 스스로 목숨을 끊었다.
- **신화 예화**: **헤라클레스**는 유노(헤라)의 끊임없는 박해를 평생 받았다.

이 예화들은 모두 악어의 상징과 이어진다 — 박해의 표적은 언제나 '맞서 싸우지 않는 의로운 자'라는 것.
