# 박해(Persecuzione) 도상에서 악어의 의미

## 질문
박해 도상에서 악어는 무엇을 뜻하는가?

## 핵심 답변
악어는 **도망치는 자만 쫓아가 싸우는 짐승**으로 알려져 있었다. 그래서 체사레 리파(Cesare Ripa)의 『이코놀로지아(Iconologia)』에서 악어는, 박해란 **저항하지 않거나 저항할 뜻이 없는 사람에게 가해지는 폭력**임을 상징한다.

## 리파의 박해 의인상 전체 구성

리파는 박해(Persecuzione)를 다음과 같은 여인의 모습으로 그리도록 지시한다.

| 요소 | 묘사 | 의미 |
|---|---|---|
| 옷 색깔 | 녹청색(verderame, 구리 녹)과 녹(ruggine, 쇠 녹)이 섞인 색 | 박해의 목적이 남을 **갉아 소모시키는 것** — 명예(onore)나 재산(roba)에 해를 입힘 |
| 날개 | 어깨에 달린 날개 | 박해는 남을 해치는 데 언제나 **재빠르고 신속함** |
| 활 | 왼손에 활을 들고 쏘려는 자세 | **멀리서도** 악담(parole malediche)으로 상처를 입힘 |
| **악어** | 여인의 발치에 그려짐 | **도망치는 자만 뒤쫓아 공격**하는 짐승 → 박해의 본질 |

## 악어 상징의 논리

리파의 설명을 풀어 보면 이렇다.

1. 고대·중세 동물지 전승에서 악어는 **맞서는 자에게는 물러서고, 등을 돌려 달아나는 자만 쫓아가 싸운다**고 여겨졌다.
2. 마찬가지로 어떤 폭력이 "박해"라고 불리려면, 그 폭력이 **스스로의 힘으로 저항하지 않거나(non voglia) 저항하기를 개의치 않는(non si curi di resistere) 사람**을 향해 행사되어야 한다.
3. 즉 대등하게 맞서 싸우는 두 편의 다툼은 전쟁이나 싸움이지 박해가 아니다. **무저항자를 겨냥한 일방적 폭력**이 박해다.

## 리파가 드는 두 가지 예

- **성인들에 대한 박해**: 남을 해칠 생각 없이 **저항하지 않고 죽임을 당한**(si lasciavano dar la morte) 순교 성인들이 겪은 것이 바로 박해다.
- **시기꾼과 험담꾼의 박해**: 시기하는 자들(invidiosi)과 중상하는 자들(detrattori)이 **명예로운 사람들의 명성(fama)을 깎아내리려** 하는 것 역시 박해다. 이들은 오직 자기 이익만 생각한다.

두 예 모두 "당하는 쪽이 맞서 싸우지 않는다"는 공통점이 있어, 악어의 습성과 정확히 대응한다.

## 암기 포인트

- **악어 = 도망치는 자만 쫓는 짐승** → 박해 = **무저항자에게 가해지는 폭력**
- 짝 개념: 녹슨 색(소모·훼손), 날개(신속함), 활(원거리 악담)과 함께 박해 의인상의 4대 속성 중 하나
- 예시 둘: ① 무저항 순교 성인 ② 명예로운 이의 명성을 깎는 시기꾼·험담꾼
